# A-Share Factor Research

This repository publishes a compact, data-free research implementation for a
point-in-time CSI 300 Alpha158 experiment. It contains code, frozen public
methodology, selected figures, and tests; it deliberately does not contain
market data, derived panels, run artifacts, or notebooks.

The Alpha158 experiment is documented in [alpha158/README.md](alpha158/README.md).
Private inputs must be supplied through `A_SHARE_DATA_ROOT`; see
[alpha158/config/data_root.example](alpha158/config/data_root.example).

Published results are historical research diagnostics, not investment advice
or evidence of deployable performance.
